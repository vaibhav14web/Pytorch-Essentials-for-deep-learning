# Pytorch-Essentials-for-deep-learning
Hello, this repository is created to understand pytorch and its core modules.

# What is Pytorch?
-> It is an open source Deep Learning Library. It combines Python's ease of use with the efficiency of the torch scientific computing framework/
-> It was originally built with Lua.
-> Torch was known for high performsnce tensor based operations especially on GPU. 

**Core features**
(1) Tensor Computations
(2) GPU Acceleration
(3) Dynamic Computation Graph
(4) Automatic Differentiation
(5) Distributed Training
(6) Interoperability with other libraries.

# Pytorch Core Modules
(1) torch

(4) torch.optim
(5) torch.utils.data -> DataLoader class and Dataset class
